The release workflows take an optional `npm-packages` input: with `publish-target: codeartifact`, each listed npm package is checked and packed before any upload (manifest rules, release version, and byte-identity with a built wheel when the package declares it), then published before the wheels with a scope-only `.npmrc` in the runner temp dir and the token only in an environment variable. Publishing is safe to re-run: the same version with the same content is skipped, with different content it fails. `node-version` pins the Node that does it.
