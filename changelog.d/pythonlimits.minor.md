The shared ruff ruleset now enforces complexity 10 and the function branch and statement limits (C90, PLR0912, PLR0915), and a managed `scripts/lint-limits.py` holds every Python file to 400 code lines against a baseline in `lint-baseline.json` that may not grow. The CI templates run it in the lint job. A repo that syncs will see new ruff findings and should clear or list them before lint is made blocking.
