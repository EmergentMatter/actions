A package whose tarball is built output can now be published without the publish job running its install or build. The caller builds and packs in its own job with no credential and uploads the tarball, and a new `npm-tarballs-artifact` input on version.yml and build-release.yml makes the publish job verify that tarball (name, version equal to the tag, files list, plain members in normal form, each named once) and publish a canonical tarball rebuilt from the bytes it checked. npm now runs in a temporary directory with a minimal environment instead of the caller's checkout, so a committed .npmrc cannot redirect the token, and a scoped registry in publishConfig is refused. Without the input nothing else changes.
