A package whose tarball is built output can now be published without the publish job running its install or build. The caller builds and packs in its own job with no credential and uploads the tarball, and a new `npm-tarballs-artifact` input on version.yml and build-release.yml makes the publish job verify that tarball (name, version equal to the tag, files list, plain members) instead of packing from the checkout. Without the input nothing changes.
