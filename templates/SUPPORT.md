# Support

## Scope

This policy covers software published by EmergentMatter: the
`emergent-matter-*` packages, `EmergentMatter/actions`, and the
SDM toolchain.

## Questions and usage help

Ask in [GitHub Discussions](https://github.com/EmergentMatter/actions/discussions),
in the Q&A category.

## Bugs and feature requests

Open an issue on the specific package's repository, using the issue
forms there.

## What is not supported

- Direct email or DMs to maintainers
- Guaranteed response times

This is a small team, and support is best-effort.
